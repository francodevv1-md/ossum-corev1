# legacy-pre-v2/README.md — Legacy previo a Knowledge V2

Estado: vigente como referencia histórica

---

## Propósito

Esta carpeta conserva documentos previos al saneamiento de Knowledge V2.

Se mantienen para trazabilidad, rescate puntual de contexto y auditoría histórica.

---

## Regla

Nada de esta carpeta gobierna.

Si un archivo de `legacy-pre-v2/` contradice documentos activos de `knowledge/`, prevalece Knowledge V2.

---

## Qué puede encontrarse acá

- módulos root-level previos a `domain/`;
- duplicados de workflow fuera del esquema canónico;
- taxonomías o políticas anteriores de Engram;
- referencias a metodologías, rutas o briefs legacy.

---

## Uso correcto

- consultar solo si falta contexto histórico;
- rescatar reglas útiles de forma explícita y mínima;
- no reactivar estos documentos como fuente canónica.
