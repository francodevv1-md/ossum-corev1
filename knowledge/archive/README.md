## Regla

Nada en archive gobierna.

Si un agente encuentra contradicción entre archive y Knowledge V2, debe obedecer Knowledge V2.

Los documentos archivados pueden servir como referencia histórica o fuente de rescate puntual, pero nunca como instrucción activa de trabajo.

## Cómo archivar

Cuando se mueva contenido viejo:

1. Mantener nombre descriptivo.
2. Agregar fecha si se sabe.
3. Indicar por qué quedó histórico.
4. No mezclar secretos.
