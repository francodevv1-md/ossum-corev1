# Implementación del dry-run core — 2026-10-01

**Resultado:** implementada una CLI local legacy-only, sin Prisma, Supabase, conexión de red ni rutas OSSUM. El matching DEV **no está implementado ni se ejecutó**. Entry point: `npm run migration:dry-run -- <flags>`, que ejecuta `python -B scripts/legacy-openai-audit/dry_run.py` (Python 3.14, solo stdlib). Contrato: `31_DRY_RUN_SPEC.md`; preflight: `37_DRY_RUN_PREFLIGHT.md`.

Archivos: `scripts/legacy-openai-audit/dry_run.py` (lector DBF acotado, tipos RawLegacyContact/Article/Surgery → NormalizedLegacy* → Candidate, validación fuente y reconciliación), `test_dry_run.py` (4 verificaciones), `package.json` (comando), `.gitignore` (solo `.tmp/consultar-plus-openai-audit/`). `company-map.local.json` privado es **simbólico** PRINC/TEST; no contiene Company.id real, credenciales ni permisos DEV. `--source-namespace` estable `consultar-plus:districorr`. `--match-mode dev-read-only` falla explícitamente antes de abrir DB.

Preflight comprueba archivos/hashes congelados de **CIRUGIA, CLIENTE, ARTICULO, CIRTIP** antes de leer registros; DBF VFP `0x30`, codepage mark `3`, anchos, tamaño, deleted marker `*` o espacio y decode cp1252 estricto. Al terminar compara de nuevo los cuatro hashes; hashes por fila SHA-256 de bytes originales. No se interpreta FPT: solo `memoPointerPresent` + `memo_not_decoded`. Las fechas pasan de `YYYYMMDD` a texto civil `YYYY-MM-DD`, sin hora ni timezone; los 60 controles congelados se leen del documento 32 y se verifican contra constantes de control para no sustituirlos. La CLI rechaza `--sample-only` junto con `--cohort`.

Salida privada: `.tmp/consultar-plus-openai-audit/<run>/records.json` contiene CIRCOD, otros códigos legacy, warnings y hashes; `aggregate.json` contiene solo conteos, categorías y hashes de tablas. Ambos deterministas; el hash semántico `reportHash` excluye hora de ejecución (no hay timestamps). No se publican nombre, DNI, CUIT, email, teléfonos ni texto clínico. `.gitignore` protege la carpeta privada; **no subir `records.json` a Git ni compartirlo como documento público**.

Reutilización productiva: ninguna. `profile.py` y `core_closure.py` tampoco se importan (tienen profiling/ejecución al importarse). Funciones explícitamente evitadas: `createContact`, `resolveCompanyContactReference`, `createArticle`, `createSurgery`, `recordStockMovement`, services de Invoice/Remito, Prisma Client y APIs/Auth. `Contact` se evalúa de forma independiente; `Article` se perfila como catálogo separado y `articleResolution.mode=NOT_REQUIRED` por Surgery. Ningún `wouldCreate`/`wouldReuse` se afirma sin adapter nativo.

**Límite de seguridad:** la CLI usa `open(rb)` + `mmap.ACCESS_READ` para origen y restringe `--out` a un hijo directo del directorio privado; no prueba que los ACL de Windows impidan mutaciones por *otros procesos*. Memoria de memos FPT e identidad nativa no forman parte de este core run. El `sourceHash` por fila cubre el puntero de memo DBF, **no el contenido FPT**.
