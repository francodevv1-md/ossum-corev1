# Auditoría independiente — método

Alcance: backup externo, inmutable; OSSUM solo lectura; excluir registros DBF marcados `*` de los universos operativos. Instrumentos: `scripts/legacy-openai-audit/profile.py` y `metrics.py`, stdlib Python 3.14, apertura `rb` y mmap `ACCESS_READ`. Salidas agregadas en `.tmp/consultar-plus-openai-audit/{inventory,profiles,metrics}.json`. Para reproducir: `python scripts/legacy-openai-audit/profile.py` y luego `python scripts/legacy-openai-audit/metrics.py` desde `ux-ui`. **No publicar perfiles crudos**: pueden contener datos personales.

Se cargó `find-skills`, se consultó skills.sh y `npx skills find` para DBF/FoxPro y data validation. La búsqueda DBF devolvió coincidencias no especializadas/de baja adopción; no se instaló ninguna. Supabase/Prisma oficiales son pertinentes para implementación futura, redundantes para lectura DBF. El lector propio solo interpreta descriptores y campos DBF; no decodifica contenido FPT ni índices CDX, y asume cp1252 para caracteres: ambas son limitaciones explícitas. Totales se comparan con contador del header y capacidad física. Ninguna conclusión de Codex/MiniMax fue leída antes de congelar 01–18.
